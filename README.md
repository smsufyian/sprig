# sprig

Isolated virtual spaces for development, testing, and CI.

## Install

**macOS / Linux**

```sh
curl -fsSL https://raw.githubusercontent.com/smsufyian/sprig/master/install.sh | sh
```

**Go install**

```sh
go install github.com/smsufyian/sprig/cmd/sprig@latest
```

## Verify

```sh
sprig --help
```
